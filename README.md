# TV Streaming Italy

App Android per lo streaming di canali TV italiani.

## Funzionalita'
- 27+ canali italiani pre-caricati (Rai, Mediaset, La7, TV8, TG24...)
- Aggiunta di canali personalizzati (URL .m3u8)
- Ricerca, filtri per categoria, preferiti
- Player HLS (ExoPlayer) con Picture-in-Picture
- Database locale Room

## Build con GitHub Actions (automatica)
Push su main -> scheda Actions -> scarica l'artifact APK.

## Build locale (opzionale)
Apri la cartella in Android Studio. Se richiesto, accetta di generare
il Gradle wrapper. Poi: Build -> Build APK(s).
